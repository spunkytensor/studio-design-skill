# Security policy

Spunky Tensor maintains the current `main` revision of this content-only skill.
There are no supported versioned releases or executable application artifacts.
Review instructions before allowing an agent to act on them; host applications,
agent tools, and the separately downloaded `npx skills` installer have their own
security policies and dependencies.

## Reporting

Private vulnerability reporting is **not enabled** as of 2026-09-29. No working
private contact route has been confirmed. Do not post exploit details, credentials,
or sensitive data in public issues. You may open a non-sensitive issue asking the
maintainer to enable a private reporting route, then wait for that route before
sharing details. This is an outstanding administration gap, not a confidential
reporting mechanism or a response-time promise.

For exposed credentials, revoke them immediately; deleting text is insufficient.
Maintainers should assign findings an owner and remediation date based on impact.
See [baseline coverage and outstanding work](docs/baseline-adoption.md).
